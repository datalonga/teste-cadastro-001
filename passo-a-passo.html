01

Como funciona

O navegador envia os dados do formulário diretamente à API do Supabase.

Frontend

Uma página estática em HTML, CSS e JavaScript, hospedada no GitHub Pages.

Banco de dados

Uma tabela PostgreSQL no Supabase, protegida com RLS e uma política de inserção.

O exemplo cadastra nome, cargo e data de contratação. Ele não mostra a lista de funcionários na página.

02

Criar o projeto Supabase

O painel do Supabase permite criar e administrar o banco pelo navegador.

  1. Crie uma conta ou entre no painel do Supabase.
  2. Crie uma organização, se ainda não tiver uma.
  3. Selecione New project.
  4. Escolha a organização, dê um nome ao projeto e defina uma senha segura para o banco.
  5. Escolha uma região próxima e crie o projeto. Aguarde a inicialização.
03

Criar a tabela e ativar RLS

Execute este SQL uma vez no SQL Editor do seu projeto.

  1. No painel do projeto, abra SQL Editor e crie uma nova consulta.
  2. Cole o SQL abaixo e clique em Run.
SQL · tabela, RLS, política e permissões 
CREATE TABLE public.funcionarios (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  nome VARCHAR(150) NOT NULL,
  cargo VARCHAR(100) NOT NULL,
  data_contratacao DATE NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

ALTER TABLE public.funcionarios
  ENABLE ROW LEVEL SECURITY;

GRANT USAGE ON SCHEMA public TO anon;
GRANT INSERT ON TABLE public.funcionarios TO anon;

CREATE POLICY "Permitir cadastro de funcionarios"
ON public.funcionarios
FOR INSERT
TO anon
WITH CHECK (
  char_length(trim(nome)) BETWEEN 1 AND 150
  AND char_length(trim(cargo)) BETWEEN 1 AND 100
  AND data_contratacao IS NOT NULL
);
Importante: a política permite que visitantes enviem novos registros como anon. Ela não concede permissão para consultar, editar ou excluir os registros. O comando acima é para executar uma vez; rodá-lo novamente pode dar erro porque a tabela ou política já existe.

04

Criar o arquivo do formulário

Crie um arquivo chamado index.html e cole nele o código abaixo.

Antes de publicar: no código, troque COLE_AQUI_SUA_URL e COLE_AQUI_SUA_CHAVE_PUBLICA pelos dados do seu projeto (passo 5).
index.html · formulário funcional 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Cadastro de Funcionários</title>
  <script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>
  <style>
    * { box-sizing: border-box; }
    body {
      margin: 0; min-height: 100vh; padding: 24px;
      display: grid; place-items: center;
      background: #f1f5f9; color: #172554;
      font-family: Arial, sans-serif;
    }
    .card {
      width: min(100%, 460px); padding: 30px;
      border-radius: 18px; background: white;
      box-shadow: 0 12px 40px #0f172a12;
    }
    h1 { margin: 0 0 8px; font-size: 1.6rem; }
    .intro { margin: 0 0 24px; color: #64748b; }
    label { display: block; margin: 16px 0 7px; font-weight: 700; }
    input {
      width: 100%; padding: 12px; border: 1px solid #cbd5e1;
      border-radius: 9px; font: inherit;
    }
    input:focus { outline: 2px solid #93c5fd; border-color: #2563eb; }
    button {
      width: 100%; margin-top: 22px; padding: 13px;
      border: 0; border-radius: 9px; background: #2563eb;
      color: white; font: inherit; font-weight: 700; cursor: pointer;
    }
    button:disabled { opacity: .6; cursor: wait; }
    #mensagem { margin-top: 16px; }
    .sucesso { color: #15803d; }
    .erro { color: #b91c1c; }
  </style>
</head>
<body>
  <main class="card">
    <h1>Cadastro de funcionários</h1>
    <p class="intro">Preencha os dados para realizar o cadastro.</p>

    <form id="formCadastro">
      <label for="nome">Nome completo</label>
      <input id="nome" type="text" maxlength="150" autocomplete="name" required>

      <label for="cargo">Cargo</label>
      <input id="cargo" type="text" maxlength="100" required>

      <label for="dataContratacao">Data da contratação</label>
      <input id="dataContratacao" type="date" required>

      <button id="btnCadastrar" type="submit">Cadastrar funcionário</button>
    </form>

    <p id="mensagem" role="status" aria-live="polite"></p>
  </main>

  <script>
    const SUPABASE_URL = "COLE_AQUI_SUA_URL";
    const SUPABASE_PUBLIC_KEY = "COLE_AQUI_SUA_CHAVE_PUBLICA";

    const supabaseClient = window.supabase.createClient(
      SUPABASE_URL,
      SUPABASE_PUBLIC_KEY
    );

    const form = document.getElementById("formCadastro");
    const botao = document.getElementById("btnCadastrar");
    const mensagem = document.getElementById("mensagem");

    form.addEventListener("submit", async (event) => {
      event.preventDefault();
      mensagem.textContent = "";
      mensagem.className = "";

      const nome = document.getElementById("nome").value.trim();
      const cargo = document.getElementById("cargo").value.trim();
      const dataContratacao =
        document.getElementById("dataContratacao").value;

      if (!nome || !cargo || !dataContratacao) {
        mostrarMensagem("Preencha todos os campos.", "erro");
        return;
      }

      botao.disabled = true;
      botao.textContent = "Salvando...";

      try {
        const { error } = await supabaseClient
          .from("funcionarios")
          .insert({
            nome,
            cargo,
            data_contratacao: dataContratacao
          });

        if (error) throw error;

        mostrarMensagem("Funcionário cadastrado com sucesso!", "sucesso");
        form.reset();
      } catch (error) {
        console.error("Erro no cadastro:", error);
        mostrarMensagem(
          "Não foi possível cadastrar. Confira a conexão e as permissões do Supabase.",
          "erro"
        );
      } finally {
        botao.disabled = false;
        botao.textContent = "Cadastrar funcionário";
      }
    });

    function mostrarMensagem(texto, tipo) {
      mensagem.textContent = texto;
      mensagem.className = tipo;
    }
  </script>
</body>
</html>
05

Conectar o HTML ao Supabase

Copie a URL do projeto e a chave publicável no painel do Supabase.

  1. No painel, abra a área de configuração do projeto e procure API Keys ou Connect.
  2. Copie a Project URL e a chave Publishable (em projetos antigos, pode aparecer como anon).
  3. No arquivo index.html, substitua os valores de exemplo:
Configuração do cliente 
const SUPABASE_URL = "https://seu-projeto.supabase.co";
const SUPABASE_PUBLIC_KEY = "sb_publishable_sua_chave";
Nunca coloque no HTML: a chave secret ou service_role, senha do banco ou qualquer credencial secreta. O HTML é público; a chave publicável é feita para uso no frontend e deve ser combinada com RLS.
06

Publicar no GitHub Pages

O arquivo do site deve se chamar index.html e ficar na raiz do repositório.

  1. Entre no GitHub e crie um repositório chamado, por exemplo, cadastro-funcionarios.
  2. Envie o arquivo index.html para a raiz do repositório e salve as alterações.
  3. No repositório, abra Settings → Pages.
  4. Em Build and deployment, selecione Deploy from a branch.
  5. Escolha a branch main e a pasta /(root), depois salve.
  6. Quando a publicação terminar, abra o endereço indicado na página do GitHub Pages.
O endereço costuma seguir o formato https://seu-usuario.github.io/nome-do-repositorio/. O GitHub mostrará o endereço exato do seu site nas configurações de Pages.
07

Testar o cadastro

Faça um envio de teste e confirme o registro no banco.

  1. Abra o endereço publicado no GitHub Pages.
  2. Preencha nome, cargo e data de contratação; clique em Cadastrar funcionário.
  3. Confira a mensagem de sucesso na página.
  4. No Supabase, abra Table Editor → funcionarios e confira se o registro chegou.
08

Segurança e próximos passos

Este é um exemplo simples para aprendizado e protótipo.

  • Mantenha RLS ativado e conceda somente as permissões necessárias.
  • Não crie uma política de leitura pública para a tabela de funcionários.
  • Como não há login, qualquer visitante pode tentar cadastrar dados. Para uso interno, adicione autenticação e políticas para usuários autenticados.
  • Para uso real, considere controles contra spam e abuso, além das obrigações aplicáveis de proteção de dados pessoais.
  • Confira periodicamente as permissões e políticas no painel do Supabase.
